# Trailnest Finds

Trailnest Finds is a camping and overlanding discovery site focused on practical outdoor gear, field guides, vehicle gear, camp kitchen, sleep systems, budget finds, and trail-ready deals.

## Site direction

- Distinct outdoor identity with forest, earth, sand, and rust tones
- Mobile-first navigation and category buttons
- Direct-to-product linking for featured gear
- Only products actually present on the site should be promoted on social channels
- Built to support affiliate products, editorial guides, deal tracking, and future newsletter growth

## Publishing

This repository is structured as a static GitHub Pages site from the repository root. The main page is `index.html`.
